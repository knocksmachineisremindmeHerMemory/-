# 『落とし主を、探しています』 note投稿戦略メモ

## 1. 市場調査メモ（Web検索＋既存知識。2026年10月時点）

### noteで読まれる創作の傾向
- **短編・読み切りの完結作品が強い**。長編連載は初回以降の離脱が大きい。初めての読者には「1記事で完結する」作品のほうが、スキやフォローにつながりやすい。
- **20〜30代の女性会社員が中心読者層**。失恋のその後、自己肯定感、仕事と恋愛の両立、「ちゃんと終わらせる」「手放す」といった、読後に「自分の話だ」と思える感情が共感されやすい（エッセイ系で人気のテーマとも重なる）。
- **派手な設定より「小さな職業もの×恋」**。あまり知られていない職場の内側（今回は遺失物係）が、独自性と読みやすさを両立させやすい。
- **創作大賞（毎年春〜夏に募集）には「恋愛小説部門」がある**。応募は大会ハッシュタグと部門ハッシュタグを付けるだけ。過去記事にタグを付けて応募する方法も紹介されていた。文字数などの規定は年・部門ごとに違うので、応募前に公式ページ（note.com/creative-award）で確認すること。開催期間外でも「#創作大賞」タグの記事は検索経由で一定数読まれる。

### 伸びるタイトルの型
- `【短編小説】` などのジャンル表示を先頭に付ける → タイムラインで小説だとすぐわかり、目当ての読者がクリックしやすい。
- **謎の残る一文型**（「〜を、探しています」「〜は、三番の棚にあります」）。読点で間を作ると余韻が出る。
- 「〇〇な私が〇〇した話」型はエッセイでは強いが、小説では安っぽく見えやすい。今回は使わない。
- 20〜30字程度に収め、スマホのカードで切れないようにする。

### ハッシュタグ
- 定番：#恋愛小説 #短編小説 #小説 #創作
- 読者層向け：#大人の恋愛 #失恋
- テーマ（検索の入口）：#忘れ物 #ショートストーリー
- コンテスト：#創作大賞 ＋ 部門タグ（その年の正式な表記で）
- 目安は8〜10個。関係の薄いタグを増やすのは逆効果。

### 文字数・読みやすさ
- 読み切り短編は**5,000〜12,000字（読了10〜20分）**が、読み切ってもらえる上限の目安。通勤時間や寝る前に読み終えられる長さ。
- スマホ前提で、**1段落1〜3文**、会話の前後は空行、場面転換は `---`。
- 冒頭3行で「いちばん多い忘れ物は傘。二番目は言えなかった言葉」という**問いと比喩**を出し、読者の手を止める。

### 有料と無料
- 検索した分析記事によると、読み物系有料記事の平均価格は約983円。有料部分の文字数と売上には、ほとんど相関がない（読み物系で相関係数0.011）。→ **「量」ではなく「続きが気になる地点」で区切ることが大事**。
- 有料コンテンツで売上が立っているユーザーは1割未満という見方もある。フォロワーが少ない段階では、**無料で信頼とフォローを集め、マガジンや連作で収益化する**ほうが合理的。
- 有料マガジンは、後から記事を足せる連載・シリーズ向き。単発の有料記事は単体で売るもの向き。

## 2. 企画

### ターゲット
- **メイン：25〜34歳の女性会社員。** 過去の恋を「終わったこと」にしたまま、なんとなく前に進めずにいる人。
- サブ：「静かな大人の恋愛もの」が好きな、本好きの男女。

### 刺さる感情フック
1. **「捨てられないから、忘れたふりをした」**：ものを手放せない気持ちを、忘れ物という制度に預けてしまう、という発想への共感。
2. **「終わった」と「終わらせた」は違う**：ちゃんと受け取ってから、ちゃんとしまう。前向きな手放し方。
3. **見知らぬ誰かが、自分の痛みを大切に扱ってくれていた**：「とても大切そうに置かれていました」という備考の一文で泣かせる。
4. **毎週金曜19時40分**：決まった時間に積み重なっていく、小さな恋のときめき。

### 独自性（オリジナルの設定）
- 主人公は**終着駅の遺失物係**。訪ねてくる男は、物ではなく**「落とし主」を探している**。
- 遺失物法の「保管期間が過ぎると、拾った人のものになる」という仕組みを、恋の終わらせ方の比喩として使う。
- 相手は**時計修理士**。「止まった時間」と「保管期間」という二つのモチーフが、祖母の腕時計を修理に出すラストで一つになる。
- 駅名・路線名（汐見台駅・港見線）、登場人物、ブランド名はすべて架空か一般名詞。

### タイトル案
1. **落とし主を、探しています** ← 採用
2. 失くしたものは、三番の棚にあります
3. 保管期間のない恋

**選んだ理由**：検索や掲示物でよく見る「〜を探しています」の言い回しだが、「物」ではなく「人」を探しているズレが、1行で謎になる。読み終えると「探していたのは澪自身でもあった」と意味が変わり、余韻が残る。短く、スマホで切れない。

### 構成（全5章＋終章、本文約9,600字）
| 章 | 内容 | 役割 |
|---|---|---|
| 一 忘れ物の二番目 | 遺失物係の日常と澪の「感情にも保管期間を」という決意 | 世界観・冒頭の掴み |
| 二 金曜日の十九時四十分 | 仁科が毎週来る／傘・缶コーヒー・クロワッサン／刻印の判明 | ときめきの積み重ね→**クリフハンガー** |
| 三 保管期間 | 湊との7年と、指輪を終電に置いてきた夜／柴田さんの言葉 | 共感の核 |
| 四 落とし主 | 拾得記録の備考／雨のロータリーで名乗る | 山場 |
| 五 受け取りのサイン | 返却票への署名／祖母の時計／海の町へ | 解放と新しい始まり |
| 終 | 窓口に戻り、冒頭の一文を言い直す | 余韻・円環構造 |

## 3. 投稿パッケージ

### タイトル
`【短編小説】落とし主を、探しています`

### リード文（本文冒頭の引用ブロック）
novel.mdの冒頭にそのまま入れてある。ほかに、TL共有やX（旧Twitter）告知用の一文：
> 「指輪の落とし主から、問い合わせはありませんでしたか」——その指輪は、私が終電に"わざと"置いてきたものだった。

### ハッシュタグ（10個）
`#恋愛小説 #短編小説 #小説 #創作 #大人の恋愛 #忘れ物 #失恋 #ショートストーリー #創作大賞 #恋愛小説部門`
※創作大賞の開催中は、大会タグ・部門タグをその年の正式表記に差し替える。開催期間外なら、最後の2つを #小説が好き #眠れない夜に などに入れ替える。

### 見出し画像のコンセプト
- **構図**：夜の駅の遺失物窓口のカウンター。手前に、透明なビニール傘（柄に小さな星のシール）と、少し開いたビロードの指輪の箱。奥はぼかした蛍光灯の光。
- **色**：夜の紺と、蛍光灯の青白い光に、指輪の銀色をひと粒。差し色に、タグの手書き文字のくすんだオレンジ。
- **文字**：右下に小さく、明朝体で「落とし主を、探しています」。サイズは1280×670。文字は画面の2割以内に抑える。
- 人物の顔は入れない（読者が自分を重ねられるように）。AI生成画像を使う場合は、その旨を記事の末尾に書いておく。

### 有料ラインについて
**おすすめ：全文無料。**
- この作品の目的は**最初のファン（フォロワー）を作ること**。読後感の良さが、スキ・フォロー・おすすめ（サポート）に直結する作品なので、課金で読者を止めるのはもったいない。
- 創作大賞やnote公式のおすすめ（ピックアップ）に乗るには、全文読めるほうが評価も拡散もされやすい。※応募規定は年ごとに公式で確認。
- かわりに**記事末尾でサポート（チップ）を受け付け**、マガジンへ誘導する。

**有料にする場合の代わり案**
- **区切る場所**：第二章の終わり「それは、私の誕生日だった。」の直後（全体の約35%）。刻印が明かされる、いちばん続きが気になる場面。
- **価格**：単品**300円**。読み物の平均（約980円）より下げ、「コーヒー1杯分で結末が読める」と思える価格にする。
- **併用**：有料ラインの前に「全5章・約1万字で完結します」と明記して、未完ではないと安心してもらう。

### 末尾のフォロー導線
novel.mdの末尾に入れてある（問いかけ→スキのお願い→フォローすると続きが届く→次回予告「次の金曜日、十九時四十分に、また。」）。作中の時刻を予告に使うことで、**毎週金曜19:40に更新する**という習慣も一緒に作る。

## 4. 続編・マガジン展開
- **連作マガジン『お忘れ物取扱所より』**（無料マガジンで始め、10話たまったら有料化を検討）
  - 1話完結の短編（5,000〜8,000字）。毎回、遺失物係に届く「誰かの忘れ物」が主役。
  - 例：「片方だけのイヤホン」（同じ曲を別々に聴いていた二人）／「ページの端が折られた単語帳」（受験生と、その母）／「柴田さんが十八年取りに行かない傘」（先輩の過去）。
  - 澪と朔の遠距離（第一・第三土曜）は、各話の最後に少しずつ進む。読み続ける理由になる。
- **続編・朔の視点**：『とても大切そうに置かれていました』
  - 二年前の終電の夜を、朔の側から描く。父とのけんか、箱を見つけた瞬間、なぜ手放せなかったのか。本編の読者向けに、**有料（300〜500円）または有料マガジン限定**にするのが向いている。
- **有料マガジン案**：「金曜19時40分の短編集」月額500円。毎週金曜19:40に1本。月1本は会員限定（番外編・あとがき・創作メモ）。
- **他のSNSとの連動**：Xやスレッズに、冒頭3行と「二番目に多い忘れ物は？」という問いかけを投稿。リプで読者の「言えなかった言葉」を集め、次の作品の題材にする（読者参加）。
- **数字の見方**：最初の72時間のスキ数／ビュー数（スキ率3%以上が目安）、フォロー転換、全文読了率（noteのアクセス状況で確認）。良かったタイトルの型と投稿時刻（金曜夜）を、次回以降も続ける。
